## Description

Tetris created in C# using **Raylib-cslo**

### Features Included

## Technologies Used

- **.NET 5.0**
- **Raylib** (graphics library)
- **Raylib-cslo** (C# binding for Raylib)
- **Newtonsoft.Json** (for JSON file management)
- **Chiptune**

## Installation

1. Download the project source code.
2. Go to the `bin/Release/` folder.
3. Launch the game by running `Tetris.exe`.

**OR**

If you prefer to run the project via VSCode or any other editor, open the `Program.cs` file and then run the following command in the terminal:

```bash
dotnet run
```
